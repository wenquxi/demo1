# 《暮色回响》游戏策划案

> 暂定名，可改。备选：《十三日回响》《灰堤纪事》。

| 项 | 内容 |
|---|---|
| 版本 | v0.2 已决策稿 |
| 用途 | 用户与协作方（workbuddy / DeepSeek）的共同参考 |
| 状态 | 关键决策已锁定（第 12 节），故事大纲与角色已定，可直接进入剧本写作 |

## 1. 一句话定位

**一款以「对话」为核心玩法的章节制群像剧。**

你是边境学园的新生，和一支四人小队一起调查周期性出现的「异变」。
没有动作捕捉，没有动作战斗——所有张力都由对话、选择、调查和文字演出承载。

- **类型**：叙事 RPG / AVG（JRPG 骨架 + 视觉小说演出）
- **表现**：3D 场景自由移动 + 2D 立绘对话（闪轨式）
- **视角**：第三人称跟随，对话时切镜头
- **单章时长**：30–60 分钟；首发目标 3 章
- **平台**：PC（Godot 4.7 / Windows）
- **分工**：你 = 创意与剧本；workbuddy = 地图与场景；我 = 系统与工具
- **关键词**：群像、羁绊、章回、异变、对话即推理

---

## 2. 四条设计支柱

### 支柱一：对话就是玩法，不是过场

大多数剧情游戏的对话是「读文本 + 按空格」，玩家是观众。
本作要求对话本身有**决策**：说什么、对谁说、什么时候说。

- 选项要付出代价（时间、羁绊、线索），不能有"全选一遍"的最优解。
- 关键场景用**限时选项**：倒计时结束 = 沉默，沉默也是一种回答。
- ❌ 反面：选项只是换个说法、结果一样。

### 支柱二：零动补也能演出

用**镜头 + 立绘 + 文字 + 声音**四件套替代动画，这是本作成本控制的核心。
一帧逐帧动画都不做，也要能把"她愣住了"演出来。

- 演出手段的排序原则：便宜的先用（停顿、压暗），贵的少用（相机运动）。
- 见第 7 节完整清单。

### 支柱三：群像与羁绊

选择的重量来自"关系"，不是数值。
队友各有立场，同一句话对不同人说效果不同；好感不是加号，是**信息差的解锁**。

### 支柱四：章节制的「日常—异变」节奏

一章 = 几天的日常 + 一次异变。日常段让玩家喘息、建立关系；
异变段把关系推到极限。**有呼吸感**，避免全程高压。

- ❌ 反面：一上来就是世界危机，玩家还没认识角色就得救世界。

## 3. 参考作品：借鉴什么，不借鉴什么

| 作品 | 借鉴 | 明确不借鉴 |
|---|---|---|
| 闪之轨迹 | 章节制、自由行动日、羁绊事件、对话立绘、限时选项、话题系统 | 导力器与复杂战斗、庞大世界观设定 |
| 逆转裁判 | 对话中的「追问 / 出示线索」作为核心玩法 | 法庭章节结构、夸张漫画演出 |
| 极乐迪斯科 | 对话选项塑造人格、内心声音插话 | 纯文本无演出、超长文本量 |
| 女神异闻录 5 | 日历推进、关系等级 | 迷宫探索与回合战斗 |
| 十三机兵防卫圈 | 多视点拼图式叙事（可选，见 M3） | 高成本的全 2D 动画演出 |

**取舍逻辑**：本作把上面所有作品的「动画/战斗成本」全部砍掉，只保留它们**用对话制造的张力**。

## 4. 世界观与舞台（✅ 已定稿）

### 4.1 设定

边境工业城镇「灰堤」。每 **13 天**出现一次「暮色」——正午天色反常地暗下来，
同时城里出现普通人无法察觉的「回响」（异常现象：重复的声响、走不出去的巷子、
不该存在的门）。

主角是新转入「哨塔学院」的特招生，天生能听见回响。
学院理事会知道暮色的真相，但一直在掩盖。

### 4.2 基调 ✅ 已定：蒸汽与铆钉的工业边境

- **为什么选它**：现有工程的地图件已经是工业方块风（`CSGBox3D` 的岩石/金属色块），
  选这个基调等于**零返工**。
- **为什么它最适合"无动补"**：蒸汽机械天生就是"会响的东西"。齿轮空转、蒸汽倒流、
  管道漏气、铆钉自己松掉——这些全部可以用**音效 + 文字**演出来，一帧动画都不需要。
- 时代感：第二次工业革命级别的技术。铆钉、黄铜、蒸汽管道、齿轮、煤气灯，
  但**没有电灯和无线电**（通讯靠人跑腿 → 天然制造"消息来得太晚"的戏剧性）。
- 「回响」的表现方式：机械重复同一个动作、齿轮空转、蒸汽倒着流。

### 4.3 舞台：灰堤（三层结构）

| 区域 | 内容 | 用途 |
|---|---|---|
| 中央钟塔区 | 钟塔、哨塔学院、理事会大楼 | 主线推进、真相 |
| 工人区 | 厂房、巷道、集体宿舍 | 调查、第二章舞台 |
| 旧港区 | 废弃码头、走私通道 | 情报交易、支线与队友个人线 |

> 三层结构的作用：**免费的空间叙事**。玩家不用被告知阶级差异，
> 从钟塔区走到工人区，屋顶变矮、灯变少、蒸汽变脏，自己就懂了。

### 4.4 小队（四人，已定名）

| 角色 | 全名 | 定位与性格 | 倾听方式 | 说话风格 |
|---|---|---|---|---|
| 主角 | 凯尔·凡特 | 哨塔学院特招生，能听见回响；习惯先听后说 | **追问**：就一句话继续深挖 | 短句，常以「……」开头 |
| A | 艾琳·卡斯特 | 军规家庭出身，说话像念条例；其实最怕被抛下 | **压制**：用身份与规则逼对方开口 | 完整句、敬语、爱说「规定上」 |
| B | 米拉·索恩 | 工人区长大，情报贩子，嘴上没把门 | **共情**：说出对方的处境换真话 | 口语、插科打诨、爱给人起绰号 |
| C | 诺克斯·维尔 | 沉默的技师，只在必要时开口，但句句要命 | **观察**：指出对方身上的细节 | 极短句，几乎不用语气词 |

**NPC 侧关键角色**

| 角色 | 身份 | 与主线的关系 |
|---|---|---|
| 薇拉教官 | 哨塔学院实战教官，小队的带队人 | 知道暮色的部分真相，一直在暗中保护四人 |
| 议事长 奥托 | 灰堤理事会首领 | 反派面：为了维持灰堤的蒸汽供应而掩盖实验 |
| 「十三号」 | 工人区失踪者，米拉的旧识 | 第二章的关键；第三章揭示他才是"原型" |

> **每人一种手段 → 同一个 NPC 有三条打开路径。**
> 重玩价值、"对话即玩法"、以及和普通视觉小说的区别，全部从这里长出来。

### 4.5 三章大纲 ⚠️ 仅为背景参考，不作准

> **第一部分（开场）已单独成文：[第一部分策划-到站.md](第一部分策划-到站.md)，以那份为准。**
> 本节的三章大纲只用来对齐基调，章节划分会在大修时重做。

| 章 | 标题 | 暮色现象 | 剧情推进 | 本章功能（写作时的自律） |
|---|---|---|---|---|
| 一 | **停摆的钟** | 正午钟塔停摆，全镇时间错位；晚到的人"还没到过" | 四人首次组队；发现钟塔机械里嵌着回响结晶 | 教学章：教会玩家「对话 → 线索 → 提问」 |
| 二 | **走不出去的巷** | 工人区出现循环巷道，进去的人反复走同一段路 | 米拉的旧识「十三号」失踪；揭出理事会在用工人做「回响耐受实验」 | 分歧章：艾琳（守规矩）与米拉（护自己人）正面冲撞 |
| 三 | **第十三天** | 暮色不再退去，全城回响同时苏醒 | 凯尔发现自己与暮色同源——他是被回响"做出来"的 | 高潮章：限时选项决定队友是否还信他 |

**每章共用同一骨架**，写作时不许跑偏：

```
日常（建立关系） → 异变（打破平衡） → 调查（用提问串线索）
  → 章末对决（纯对话，不是战斗） → 结算（关系变化 + 新线索 + 钩子）
```

> 「章末对决（纯对话）」是本作最需要下功夫的地方：
> 高潮不是打赢谁，而是**用收集到的线索把对方逼到无话可说**。
> 这和《逆转裁判》的乐趣同源，但不需要任何动作演出。

### 4.6 语气示例（这段就是 M1 要写的东西，非最终格式）

```
> 钟塔停摆后的第十七分钟。蒸汽从管道的裂缝里漏出来，像一声很长的叹息。

米拉: 钟塔停了两小时，全城的钟都慢了半拍——只有理事会那只怀表走得准。

凯尔: （他们已经在钟塔下面站了很久了。）

艾琳: 规定上，学生不得靠近钟塔区。我们该回去。

米拉: 规定上，你也不该在这儿。

【选项】
  → 「教官，你也听见了吧。」
  → 什么都不说

  ← 选前者：
	凯尔: 齿轮在重复同一句话。重复了很久。

  ← 选后者：
	> 沉默比问题更响。

【合流】
薇拉教官: ……跟我来。
```

这段同时展示了五件事：**旁白**（`>`）、**名牌**、**内心独白**（括号）、
**选项**、**分支合流**。语气参考：米拉用破折号和口语，艾琳用书面语和「规定上」，
凯尔几乎不解释自己。

## 5. 核心循环

### 5.1 宏观（一章）

```
章首（标题演出）
  → 日常段（自由行动 2~3 天）
	→ 事件段（异变发生，主线推进）
	  → 调查段（进入异常区域，用线索提问解谜）
		→ 章末高潮（对决/真相揭露）
		  → 结算（羁绊变化、新线索入库、下一章钩子）
```

### 5.2 微观（一天）

| 阶段 | 玩家在做什么 | 系统支撑 |
|---|---|---|
| 自由行动 | 场景里走动、和 NPC 闲聊、触发支线 | 对话系统、羁绊 |
| 关键对话 | 做选择，承担后果 | 限时选项、flag |
| 调查 | 把收集到的线索词"问"出去，串起真相 | 线索提问系统 |
| 结算 | 看羁绊变化、日期 +1 | 存档、日历 |

### 5.3 一局的"爽点"分布

每 10 分钟至少要有一次：**信息反转**、**关系变化**、**演出高光**（三者之一）。

## 6. 系统清单（按优先级）

### P0-a 对话系统 —— 第一里程碑的全部内容

| 能力 | 作用 | 成本 |
|---|---|---|
| 名牌 + 说话人专属配色 | 一眼分清谁在说 | 低 |
| 逐字显示 + 标点停顿 | 节奏感；。！？ 处自动多停一拍 | 低 |
| 立绘左右站位 | 对话有"面对面"的空间感 | 低 |
| 表情差分切换 | 替代面部动画 | 低（一张图一个表情） |
| 非说话者压暗 | 焦点管理，替代运镜 | 低 |
| 旁白模式（无名牌、居中或斜体） | 心理描写与场景描述 | 低 |
| 选项（鼠标 + 键盘） | 决策 | 低 |
| 限时选项 + 沉默选项 | 制造压力 | 中 |
| 历史记录（可回溯重读） | 长对话必备 | 中 |
| 自动播放 / 已读文本快进 | 尊重玩家的时间 | 中 |
| 演出指令：相机、黑边、淡入淡出、等待、震屏 | 见第 7 节 | 中 |
| 音频钩子：BGM / SE / 语音 | 情绪的一半是声音 | 低（先留接口） |
| 富文本：强调色、字号、内心之声 | 文字本身的演出 | 低 |

### P0-b 剧本数据与分支

- **纯文本剧本**，作者（你）直接写，git 可 diff，不需要开编辑器。
- 支持：说话人、旁白、选项、跳转、标签、flag 设置与条件跳转。
- **校验器**：自动检查断链、未定义 flag、角色名拼写、空行异常。
  → 长篇剧情必然出现断链，这个工具越早做越省钱。

### P0-c 线索提问系统（差异化核心）

**把"读对话"变成"用对话"。**

1. 对话中自动/手动收集「线索词」（例：`停摆的钟`、`理事会的印章`）。
2. 调查阶段，玩家从线索库里选一个词，向某个角色"问"出去。
3. 不同角色对不同线索反应完全不同：有的给新线索，有的翻脸，有的沉默。
4. 线索之间可以组合，触发对方无法回避的追问。

这是本作区别于普通 AVG 的关键，也是唯一需要"设计谜题"的地方。
✅ 已定：作为 M1 的核心亮点，也是本作唯一的护城河。

### P1 第二里程碑

- 羁绊系统（不是数值条，是**解锁**：够高才看得到对方的支线）
- 自由行动时段（在有限次行动里选择去陪谁）
- 存档：多槽位 + 章节回放
- 已读文本管理（跨存档共享）

### P2 后续

- **抽象战斗**：见 6.1
- 日历 / 图鉴（人物、线索、地点）
- 语音预留、本地化预留

### 6.1 「抽象战斗」怎么做到不需要动补

传统战斗要动画，本作改成**指令式演出**：

```
选择指令（攻击 / 掩护 / 倾听）
  → 立绘特写 + 文字演出（"她用枪托撞开了那扇门。"）
	→ 数值结算 → 结果用文字与表情差分呈现
```

本质是"带数值的对话场景"，和对话系统共用同一套演出能力，
所以**做战斗几乎不增加新系统**——这也是本作把战斗降到 P2 的底气。

## 7. 「剧情演绎」能力清单（无动补方案）

按**成本从低到高**排序。这一节是支柱二的落地手册。

| 目标情绪 | 可用手段 | 需要动画资源？ |
|---|---|---|
| 平静叙述 | 立绘呼吸（上下浮动 1~2 px + 眨眼） | 否，纯补间 |
| 惊讶 | 表情差分 + 0.1s 白闪 + 停顿 0.3s | 否 |
| 紧张 | 压暗背景 + BGM 停顿 + 相机缓慢推近 | 否 |
| 愤怒 | 名牌抖一下 + 震屏 2 px + 文字逐字加速 | 否 |
| 尴尬 | 长停顿 + 旁白插话 + 立绘轻微位移 | 否 |
| 转折 | 黑边收窄 + BGM 切曲 + 停一拍 | 否 |
| 回忆 | 画面降饱和 + 叠一层白 + 字号变小 | 否 |
| 冲击 | 全屏白 → 黑 → 静音 0.5s → 场景音 | 否 |
| 时间流逝 | 淡入淡出 + 环境音渐变 | 否 |
| 角色移动 | 场景内补间位移 + 转身 | 否 |

**示例：完整演出一次"她愣住了"**

| 时间 | 发生什么 |
|---|---|
| 0.0s | 台词断在一半（剧本里就是半句） |
| 0.0–0.2s | 立绘表情从「平常」切到「怔住」，非说话者压暗 |
| 0.2s | BGM 停 |
| 0.2–0.8s | 相机推近 30cm，停 0.6s（这里是留白） |
| 0.8s | 旁白：「她没有回答。」 |
| 1.6s | BGM 以低音量重新进入 |

全程零动画资源，观感却比"她愣住了。+ 动画"更好。

## 8. 里程碑 M1：垂直切片（只做对话交互）

**目标**：10 分钟可玩片段，证明「对话本身好玩」。

### 包含

- 一段 100–150 行剧本，含旁白 / 名牌 / 选项 / 分支 / flag
- 2 个立绘位（**占位色块即可**，先不画美术）
- 限时选项 1 处、沉默选项 1 处
- 线索词收集 + 至少 1 次"提问"交互
- 历史记录
- 1 个存档槽

### 不含

战斗、地图、美术资产、语音、羁绊数值。

### 验收标准（可测）

1. 剧本所有分支可达，flag 判定正确，**无断链**（校验器自动跑）。
2. 关掉立绘和音效，纯读文本仍能读懂剧情。
3. 演出不依赖任何逐帧动画资源。
4. 每段对话都能被脚本自动跑完，可做回归测试。
5. 中文文本无缺字、无排版溢出（需实机截图确认）。

### 为什么先做这个

对话系统是**其余一切系统的底座**：羁绊、战斗、调查全都复用它的演出能力。
它做对了，后面全是拼装；它做歪了，后面全得返工。

## 附：为什么不直接做《闪之轨迹》的完整形态

闪轨的完整体验 = 群像剧情 + 自由行动 + 羁绊 + 战术战斗 + 大地图 + 全语音。
其中**只有前两项依赖本作的核心能力（对话）**，后四项都是独立的大工程。

所以本作的策略是：**把前两项做到远超同人水准，后四项砍掉或降级。**
用一句话概括——**不做"小闪轨"，做"只用对话就能撑住的闪轨"。**
