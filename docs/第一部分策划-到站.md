## 2. 世界规则（这三条是整个第一部分的地基）

1. **暮色**：每 13 天一次，正午开始，持续约 20 分钟。天色反常变暗。
2. **暮色期间，机械会重复**：钟停在原地、齿轮空转、蒸汽倒流、推车自己滑回原位。
3. **暮色期间，记录会停在「最后一件被记下的事」上，之后发生的事一件都不算数。**
   **但人的记忆不受影响。**

### 为什么是这三条

规则 3 是本作存在的理由：

> **记录会撒谎，只有人记得。**

所以玩家唯一的武器是"问人"。这就是「对话即玩法」在世界观里的合法性——
不是为了省成本才做对话，而是**这个世界里只有对话是可信的**。

> ⚠️ 大修时请保留规则 3，其余随便改。它是整套玩法的地基，抽掉它，
> 对话就退化成过场动画的替代品。

## 3. 因果链（逻辑自检表）

这一节是本文的核心。任何一行不成立，玩家就会觉得"作者在硬推"。

| # | 发生的事 | 玩家怎么知道 | 推出下一步 |
|---|---|---|---|
| 1 | 凯尔坐蒸汽列车去灰堤的哨塔学院报到 | 车厢旁白 + 艾琳搭话 | — |
| 2 | 列车长广播：蒸汽压力异常，晚点约 20 分钟 | 广播（只有声音，没有画面） | 记下线索「晚点二十分钟」 |
| 3 | 艾琳提到十三天前军港的天色暗过一次，灰堤人叫它「暮色」 | 艾琳台词 | 记下线索「十三天」 |
| 4 | 列车 12:00 整进站，**暮色在同一秒降临** | 演出（第 7 节）：灯暗、汽笛走音 | 时间上的巧合 = 可疑 |
| 5 | 站台的钟停在 **11:40**，二十分钟没走过一格 | 旁白描述 + 玩家看得见 | 记下线索「停在十一点四十的钟」 |
| 6 | 站长说：登记簿上这班车**还没有到** | 站长台词 | 与亲眼所见冲突 |
| 7 | 登记簿确实没有这班车 | 站长翻给凯尔看 | 证明"不是他记性差" |
| 8 | 玩家用「晚点二十分钟」**提问**站长 | 提问系统（教学） | 站长无法解释：晚点也没被记下 |
| 9 | 凯尔意识到：记录停在"列车该到"的那一刻，之后的二十分钟全丢了 | 凯尔内心独白 | 新线索「消失的二十分钟」 |
| 10 | 走到站外，全城钟表都停在 11:40，**只有钟塔停在 12:00** | 场景描写 | 新问题：为什么它不一样 |
| 11 | 玩家用「消失的二十分钟」**提问**诺克斯 | 提问系统（第二次，巩固） | 诺克斯指出钟塔是唯一的例外 |
| 12 | 薇拉教官出现：「上一次是十三天前。……跟我来。」 | 收尾台词 | 第一部分结束，钩子成立 |

### 两个必须守住的顺序

1. **第 6、7 行必须早于第 8 行。**
   先让玩家相信"记录不会错"，再让记录出错。顺序反了，冲击力归零。
2. **第 10 行必须晚于第 9 行。**
   玩家得先接受"记录全城都坏了"，才有资格看见"唯独钟塔没坏"。
   否则钟塔只是个布景，不是谜题。

## 5. S1 车厢内 —— 《同路人》

- **地点**：三等车厢。窗外是灰堤郊外的煤烟与铁架。
- **在场**：凯尔、艾琳（还有广播里的列车长）
- **作用**：建立凯尔与艾琳的关系基调；埋下两条线索。

```
> 蒸汽列车晃了三个小时。窗外的煤烟把天空擦成一块脏抹布。

凯尔: （报到日。特招生。哨塔学院。）

艾琳: 请问，这里有人吗。

凯尔: ……没有。

艾琳: 谢谢。

> 她把行李摆得笔直，膝盖并拢，双手放在膝盖上。

艾琳: 你也是去哨塔学院的吧。特招生。

凯尔: 嗯。

艾琳: 艾琳·卡斯特。军港来的。
艾琳: 规定上，报到日迟到要写检讨书。所以我在车上已经写好了一份。

凯尔: （她手里确实拿着一张纸。）
```

### 选择 1（教学：选项有后果）

```
【选项】
  A → 「你写了什么？」
  B → 「还有多久到？」
  C → 什么都不说
```

| 选项 | 艾琳的反应 | 后果 |
|---|---|---|
| A | 「……写了三百字。你要看吗。」（她真的递过来） | `erin_impression += 2` |
| B | 「时刻表上是十一点四十。」（她把时刻表背出来了） | `erin_impression += 1`；记下线索「十一点四十」 |
| C | 她等了三秒，收回视线，把纸折好。 | `erin_impression += 0`，之后她的台词更短 |

> **设计意图**：三个选项没有"最优解"，只有"你想和这个人建立什么关系"。
> 这是支柱一「选项要付出代价」的最小样本——代价就是关系本身。

### 广播与线索（教学：听到的话会进线索库）

```
【广播】因蒸汽压力异常，本次列车晚点约二十分钟。给各位旅客带来不便，敬请谅解。

艾琳: 二十分钟。……规定上没有这一条。

凯尔: （蒸汽压力异常。铁路上天天有的说法。）

艾琳: 你常来灰堤吗。

凯尔: 第一次。

艾琳: 我也是。上一次是三年前。
艾琳: ……十三天前我还在军港。那天正午，天色暗过一次。军港说是「云」。

凯尔: （十三天。）

艾琳: 灰堤的人不这么叫。他们管它叫——「暮色」。
```

**线索入库（自动，带一次明显的 UI 提示，让玩家记住这个动作）**

- 🔑「晚点二十分钟」——来自广播
- 🔑「十三天」——来自艾琳
- 🔑「十一点四十」——只有选 B 才有

> 「十三天」在**第一部分不会被用到**。它是故意留的悬线，
> 结尾由薇拉教官接住（第 12 行）。玩家会因此觉得"我听到的话是有用的"。

### 进站（暮色降临）

```
> 列车在十二点整进站。

凯尔: （……正好十二点。）

> 灯在同一瞬间暗了一格。汽笛走了音。
```

## 6. S2 站台 —— 《没有这班车》

- **地点**：灰堤站，两股道，一座铁架雨棚。
- **在场**：凯尔、艾琳、站长、（背景里的旅客）
- **作用**：核心矛盾爆发；教会玩家「提问」。

### 6.1 暮色演出（详见第 7 节）

暮色在这里降临。**全程零动画**：只调灯光、音量、和文字。

### 6.2 限时选择（教学：沉默也是回答）

站台上的所有人同时安静下来之后：

```
【限时 8 秒】
  A → 跟着人群往出口走
  B → 站在原地不动，看那口钟
  C → （不选）
```

| 选项 | 结果 | 后果 |
|---|---|---|
| A | 艾琳拉住你的袖子：「等一下。」 | 无 |
| B | 你看清钟停在 11:40 | 记下线索「停在十一点四十的钟」 |
| C | 默认执行 B，但旁白改成：「你没有动。你也不知道为什么。」 | 同上，多一句独白 |

> **设计意图**：这是"限时选项 + 沉默选项"的第一次出现。
> 三个结果都能继续，但玩家会立刻明白：**这里不选，也是一种选**。

### 6.3 站长（先让玩家相信记录，再让记录出错）

```
站长: 两位。出站口在那边。

凯尔: 我们刚到。

站长: 刚到？
站长: ……登记簿上，这班车还没有到。

凯尔: （他翻给我看。最后一页是十一点四十，往上都是空行。）

站长: 我一辈子在这站台上。车到没到，我比谁都清楚。
站长: 记录上没有。那就是没有。

艾琳: 我看了表。列车进站的时候，是十二点整。

站长: 那你的表坏了。
站长: 我这儿所有的钟，都停在十一点四十。
```

**到这一步为止，玩家应该站在站长那边**：
记录清楚、他干了三十年、凯尔的证据只有"我记得"。

### 6.4 第一次提问（核心教学）

```
【提问】
  可用线索：
	🔑 晚点二十分钟
	🔑 十三天
	🔑 十一点四十        （若 S1 选过 B）
  → 选择「晚点二十分钟」
```

```
凯尔: 列车长广播过。蒸汽压力异常，晚点二十分钟。
凯尔: 十一点四十加二十分钟，就是十二点整。我们没记错。

站长: ……

> 他低下头，又翻了一遍登记簿。这一次他翻得很慢。

站长: 没有晚点记录。
站长: 铁路上的晚点，是要登记的。二十分钟，也要登记。
站长: 可这二十分钟——哪儿都没有。

凯尔: （记录停在列车"该到"的那一刻。）
凯尔: （之后发生的事，一件都没被记下来。）
```

**新线索：🔑「消失的二十分钟」**

> **设计意图**：这是全篇最重要的一次交互。
> 玩家不是"读"到了真相，而是**用它自己收集的线索把 NPC 逼到了墙角**。
> 这就是本作和普通视觉小说的分界线——第一次尝到，就在开场第 6 分钟。

## 7. 演出标注：暮色降临的 6 秒

**全部手段只用灯光、音量、和文字。零动画资源。**

| 时间 | 画面（只调参数） | 声音 | 文字 |
|---|---|---|---|
| 0.0s | 站台灯同时暗一格 | 环境音整体压低 6dB | — |
| 0.3s | 天色偏黄（环境光偏色） | 汽笛音高下滑（走音） | 旁白：汽笛走了音。 |
| 1.0s | 站台钟的秒针停住 | 秒针「嗒」一声，然后没了 | — |
| 1.2s | 站台上所有人同时停下 | 人声全部消失 | 旁白：站台上没有人说话。 |
| 2.0s | 蒸汽从管道口倒着飘回管道 | 蒸汽声倒放 | 凯尔：（蒸汽在往回走。） |
| 2.8s | 搬运工的推车自己滑回原位，重复三次 | 木轮声 ×3 | 凯尔：（第三次了。） |
| 4.0s | 一切照旧，只有钟不动 | 低频齿轮空转声，从钟塔方向传来 | — |
| 6.0s | 亮度恢复正常 | 环境音回来，**但少了钟声** | 站长：今天的车，还没到。 |

> 最后一格是重点：**声音回来了，但少了一个**。
> 玩家说不出少了什么，只觉得不对——这正是我们要的。

### 提问交互的表现

- 屏幕下方浮出线索列表（横排小卡片，键盘左右选，回车确认）
- 选中后，凯尔会说一句"把线索问出去"的台词（每个 NPC × 每条线索都有专属回答）
- NPC 回答后，线索卡片如果产生了新线索，会**闪一下并存进库里**

## 8. S3 站前广场 —— 《停在十一点四十的城》

- **地点**：站前广场。正中一条大路通向钟塔。
- **在场**：凯尔、艾琳、米拉、诺克斯、（远处的薇拉教官）
- **作用**：四人凑齐；第二次提问；钩子。

### 8.1 城市的时间

```
> 广场的钟、店铺的挂钟、报时的铜铃——全部停在十一点四十。
> 只有远处那座钟塔，指针停在十二点整。

凯尔: （全城都停在同一刻。）
凯尔: （唯独它，走到了十二点。）
```

### 8.2 米拉与诺克斯出场

```
米拉: 喂，新来的。

> 她靠在灯柱上，嘴里叼着一根没点着的烟。

米拉: 你们俩站在那儿看钟看了一分钟了。看出来了什么没有？

艾琳: 规定上，我们不该和陌生人——

米拉: 米拉·索恩。工人区。现在不算陌生人了。

诺克斯: 钟塔。

米拉: ……他说话了。今天太阳从西边出来了。

诺克斯: 十二点。只有它。
```

> 诺克斯的台词规则：**极短句，不用语气词，只说他观察到的事实。**
> 他每次开口都是在替玩家做"观察"——这是他存在的全部意义。

### 8.3 第二次提问（巩固教学）

```
【提问】
  可用线索：
	🔑 消失的二十分钟
	🔑 十三天
  → 选择「消失的二十分钟」
```

```
凯尔: 记录只到十一点四十。之后的二十分钟，全城都没记下来。
凯尔: 可钟塔走到了十二点。

诺克斯: 它不是"记下来"。
诺克斯: 它是唯一数到十二点的那一个。

凯尔: （全城都在重复十一点四十。）
凯尔: （只有它，走完了那二十分钟。）
```

**新线索：🔑「唯一走到十二点的钟」**

> 这就是第一部分的**真相碎片**，也是钩子。
> 玩家现在手上有一个明确的问题：**钟塔为什么不一样？**
> 这个问题足够撑到第二部分，而且不需要任何主题来支撑。

### 8.4 收尾

```
> 蒸汽从广场边的管道里漏出来，像一声很长的叹息。

米拉: 我说，新来的。你今天最好别乱走。

艾琳: 规定上——

米拉: 规定上，你也不该在这儿。刚才不是说过一遍了？

薇拉教官: 上一次是十三天前。

> 没有人注意到她是什么时候站到那里的。

薇拉教官: ……跟我来。
```

**第一部分结束。**

| 🔑 晚点二十分钟 | S1 广播 | ✅ S2 提问用 |

## 11. 节奏表

| 时间 | 场景 | 情绪 | 玩家在做什么 |
|---|---|---|---|
| 0:00–0:30 | S1 | 平静、日常 | 读旁白 |
| 0:30–2:00 | S1 | 轻微紧张 | 选择 1 |
| 2:00–3:30 | S1 | 好奇 | 听广播与十三天 |
| 3:30–5:30 | S2 | **不安** | 看暮色演出、限时选择 |
| 5:30–8:00 | S2 | **对抗** | 与站长对峙、第一次提问 |
| 8:00–10:30 | S3 | 松一口气 | 认识米拉与诺克斯 |
| 10:30–12:30 | S3 | **重新紧张** | 第二次提问、薇拉出现 |

节奏设计：**每 3 分钟必须换一次情绪**，且"不安 → 松口气 → 重新紧张"的波形
比"一路紧张"更容易让人记住。

### 我认为这一部分最可能被大修的三处

1. **米拉和诺克斯的出场太巧**——两个人刚好都在广场上。这是为了在 12 分钟内凑齐四人
   而做的妥协，逻辑上最脆。建议你给一个理由（比如米拉本来就在等这班车）。
2. **限时选择 8 秒**——8 秒是我拍的，实际得试玩才能定。
   太短会让人慌乱跳过，太长就没有压力。
3. **站长的立场**——他现在是"制度的执行者"，比较中性。
   如果给他一点私心（比如他知道些什么却不敢说），会更好看，但会提前泄底。

## 附：为什么第一部分只能是这个

开场要同时完成"教学"和"吸引人"，只有一条路：
**让玩家在一个完全正常的场景里，遇到一件完全不对的事，而且不对的地方他能亲手查出来。**

所以第一部分的结构注定是：

```
正常（车厢） → 异常（暮色） → 记录说谎 → 玩家用对话把它揭穿
```

这不是我选的，是这个类型的开场唯一能同时做到"教机制"和"抓人"的形状。
你要大修的话，**可以换场景、换角色、换台词，但这四段的顺序动不了**——
动了顺序，玩家就会在还没学会提问的时候，先被要求提问。
