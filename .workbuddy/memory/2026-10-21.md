- **合并 feature 分支后一定要复查 `run/main_scene`**：两个分支各改过一次入口时，
  git 会静默取「只有一边改过」的那一边，合完的默认启动场景可能已经不是你以为的那个。
  预演用 `git merge-tree --write-tree --name-only A B`，不改工作区就能看冲突。
- **`Input.action_press()` 不产生事件**：它只改动作状态，`_unhandled_input` / `is_action_pressed(event)`
  都收不到。无头脚本里模拟按键必须 `Input.parse_input_event(InputEventAction)`，
  否则会得到「按了没反应」的假故障。
- **多 agent 共享工作区**：改文件前先看 mtime。撞上对方正在写的文件时，
  宁可等或绕开，也不要「顺手合并」——两边都加同一个 @export 会直接把脚本变成 Parse Error。
- **蒙皮网格的真实尺寸由骨骼决定**，`MeshInstance3D.get_aabb()` 是绑定姿势、不含骨骼。
  量身高要量世界空间的骨骼跨度；在根节点上缩放对骨骼跨度是线性的。
